# Set up an AI team

Create coordinator, coding and review sessions that can message each other.

1. Choose **Tools > AI Manager > Templates** and confirm the built-in **Coordinator**, **CoderPeer** and **ReviewerPeer** entries are available.
2. Choose **Create Session**, select an open project and a configured backend, choose **Coordinator** for both **Config Template** and **Session Instructions**, then choose **Create & Open**.
3. Create **CoderPeer** and **ReviewerPeer** sessions for the same open project and backend, selecting their matching **Config Template** and **Session Instructions** entries.
4. In each session, check **⚙ > Session Configuration > MCP Tools**: **Peer messaging** is on and **Allow inter-AI communication** is ticked.
5. In the Coordinator's tab, ask it to give the coder a small task and have the peer reviewer check it.
